## Smart Contract
Our core MicroMinds Escrow protocol operates as a pull-over-push smart contract running efficiently on the Monad Testnet. It natively manages user MON balances and enables a trusted backend operator to handle dynamic API reservations. 
[Read the full documentation here](./packages/contracts/README.md).
